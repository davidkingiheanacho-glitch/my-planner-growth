MY PLANNER PWA
===============
This is an installable offline web app.

Files:
- index.html  main app
- manifest.json PWA information
- sw.js offline service worker

To install on Android:
1. Put these files on a web server/hosting that supports HTTPS.
2. Open the app URL in Chrome.
3. Use the browser menu and choose "Add to Home screen" or "Install app".

Tasks are stored locally on the device using localStorage.
